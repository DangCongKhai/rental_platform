# Usability

Responsive desktop/tablet/mobile, consistent rentOS design, semantic controls and keyboard focus. Heart has accessible saved/unsaved label and pressed state; preserve card navigation when clicking it. Distinguish pending enquiry from unconfirmed tenancy and proposed versus agreed rent. Show field errors, loading/empty/unavailable/retry states. Guests get explicit login prompt. Shared amenities/private equipment and current advertising/agreement policies are labeled separately.

Validation is part of feature/engineering issues and PR evidence. Tool versions/configuration must match the local installed framework; no invented pass result.
