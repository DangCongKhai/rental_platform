# Caching

Course Task6c requires measured selection of browser/server/CDN caching plus expiration/revalidation and invalidation. Cache only safe public DTOs; gate current suspension/hide and availability before serving. Invalidate on property/unit/media/policy/content, publication/suspension and allocation changes. Private favourites/inbox/request/contract responses are account scoped and not shared; one user must never inherit another red heart. Test stale cache against suspend and proposal conflict; cache cannot authorize allocation.

Validation is part of feature/engineering issues and PR evidence. Tool versions/configuration must match the local installed framework; no invented pass result.
